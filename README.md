# 💻 Dev Board - A5 Assignment

A responsive and visually organized **Developer Leaderboard** project built with HTML and CSS. It displays developer profiles, ranks, and details in a clean, grid-based layout. This project is part of an assignment focused on layout mastery and frontend presentation.

---


## 🔧 Technologies Used

- **HTML5**
- **CSS3**


## ✨ Main Features

- 👩‍💻 Developer profile cards
- 🏆 Ranking or leaderboard-style layout
- 📱 Fully responsive design (desktop, tablet, mobile)
- 🎯 Clean UI with modern styling
- 🧱 Grid and flexbox-based layout

---

## 📦 Dependencies

No external dependencies or frameworks.  
This project is built with:
- HTML
- CSS
